# Packing List

## Rules
1. Base clothing on the **actual temperature range and rain** from the weather
   research. State the range at the top ("Highs 64-68°F, lows 52-55°F, one rainy day").
2. Add items for **planned activities** (swimsuit for beaches, comfy walking shoes
   for hilly cities, one dressier outfit for a nice dinner or night out).
3. Include **travel essentials**: ID/passport, chargers, the right **plug adapter**
   (US travelers abroad need one for most of Europe, UK, etc.), meds, a small
   first-aid kit.
4. Include a short **"Shared items"** section the group can split so no one
   overpacks (one hair dryer/straightener, one speaker, one first-aid kit, sunscreen).
5. Keep it carry-on friendly: give clothing as counts ("3 tops"), and suggest
   re-wearing.
6. Never repeat an item across sections.

## Output format
Markdown checklist (`- [ ] item`) under these headings:
Clothes · Shoes · Toiletries & beauty · Tech · Documents & money · Shared items (split these)
